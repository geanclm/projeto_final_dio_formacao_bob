## Sobre o Projeto

Este repositório contém o projeto de conclusão do bootcamp **IBM Bob: IA de Nível Empresarial para Desenvolvedores e Tech Leaders**, oferecido pela [DIO (Digital Innovation One)](https://web.dio.me/track/6c94a3da-1f22-45f6-be56-a2bad071ef51?tab=about) em parceria com a **IBM**.

O projeto reúne os conhecimentos adquiridos ao longo do bootcamp, demonstrando na prática o uso do **IBM Bob** — o agente de IA da IBM voltado para o ciclo completo de desenvolvimento de software (SDLC).

### Descrição

Agentes de IA já fazem parte do ciclo de desenvolvimento de software, de requisitos ao deploy. Saber trabalhar com esses agentes virou uma habilidade técnica concreta, e este bootcamp foi criado exatamente para isso.

O conteúdo cobre de forma prática o **IBM Bob**, parceiro de IA da IBM para o SDLC completo, abordando:

- Instalação e configuração do agente
- Modos de operação do IBM Bob
- Integração ao fluxo Git
- Extensão via MCP (Model Context Protocol)
- Boas práticas de segurança em projetos reais

O bootcamp é encerrado com a entrega de um projeto publicado no GitHub — este repositório é essa entrega.
